# Seslerin Rengi - 22 Ekim Dünya Kekemelik Farkındalık Günü

Bu proje, 22 Ekim Dünya Kekemelik Farkındalık Günü için tasarlanmış modern, mobil uyumlu ve editoryal bir web sitesidir.

## Proje Dosyaları
- `index.html`: Web sitesinin ana kaynak kodudur (Tüm stiller, Tailwind CSS, SVG logolar ve etkileşimli bölümler dahildir).

## GitHub ve Vercel ile Yayınlama Adımları

1. **GitHub'a Yükleme:**
   - GitHub hesabınıza giriş yapın ve yeni bir depo (`repository`) oluşturun (Örn: `seslerin-rengi`).
   - `index.html` dosyanızı bu repoya yükleyin (`Add file` -> `Upload files`).

2. **Vercel ile Yayınlama:**
   - [Vercel](https://vercel.com/) hesabınıza giriş yapın.
   - **Add New -> Project** seçeneğine tıklayın.
   - Oluşturduğunuz GitHub reposunu (`seslerin-rengi`) seçin ve **Import** deyin.
   - Hiçbir ayarı değiştirmeden **Deploy** butonuna tıklayın. Siteniz saniyeler içinde canlıya alınacaktır!
